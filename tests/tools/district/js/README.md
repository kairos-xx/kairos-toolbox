## Directory contents

### Files

- [`api.test.mjs`](api.test.mjs) — Tests for the small client that talks to the dashboard's API.
- [`app.test.mjs`](app.test.mjs) — Behavioral tests for the live dashboard and ANSI terminal.
- [`forms.test.mjs`](forms.test.mjs) — Tests for the forms built from a command's parameter specification.
- [`host.test.mjs`](host.test.mjs) — Tests for the overview's host panel.
- [`kit.test.mjs`](kit.test.mjs) — Tests for the shared formatters and DOM builders.
- [`palette.test.mjs`](palette.test.mjs) — Tests for the command palette: find a command, fill in its form, see the result.
- [`pure.test.mjs`](pure.test.mjs) — Tests for the routing, filtering and console layout logic, which need no DOM.
- [`sandbox-dom.mjs`](sandbox-dom.mjs) — Minimal deterministic DOM sandbox for dashboard behavioral tests.
- [`sheet.test.mjs`](sheet.test.mjs) — Tests for the layered sheet that holds a command's form.
- [`uris.test.mjs`](uris.test.mjs) — Tests for the URI screen: create, copy, run, revoke and redeem.
- [`widgets.test.mjs`](widgets.test.mjs) — Tests for the widget renderer that turns command results into DOM.

No subdirectories.
